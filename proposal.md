# Proposal

## What will (likely) be the title of your project?

A Student Appointment Organizer

## In just a sentence or two, summarize your project. (E.g., "A website that lets you buy and sell stocks.")

A web application that helps users upload and organize student appointments by meeting type (in-person or Zoom). The app processes the data and displays a summary and count of appointments by type.

## In a paragraph or more, detail your project. What will your software do? What features will it have? How will it be executed?

This software will allow users to upload an Excel file containing student appointment data. It will automatically sort the appointments by meeting type (in-person or Zoom), clean up inconsistent data, and provide a summary of the total number of appointments and their types. The user can view a breakdown of in-person and Zoom meetings, as well as download the organized data in separate files for each meeting type. The app will be executed through a simple web interface built using Streamlit, which will allow users to easily upload the file, process it, and view or download the results.
